# Contributing

Contributions are welcome if they keep the repository educational, openly reproducible, and independent of nonpublic mission work.

1. Open an issue describing the scientific question or bug.
2. Add a test reproducing the behavior or validating the mathematics.
3. Keep units explicit and use small, documented, generic examples.
4. Run `python -m pytest` and `thermalphysics verify`.
5. Submit a pull request explaining numerical assumptions and limitations.

Please do not contribute nonpublic mission datasets, proprietary simulation kernels, or export-controlled material. Include attribution and license details for external assets.
