# Data provenance, confidentiality, and disclosure

This project is independently constructed from public physical principles. It intentionally uses generic slab dimensions, illustrative material coefficients, and synthetic scenarios.

**It contains none of the following:**
- Nonpublic NASA/JPL/industry source code or engineering models
- Mission telemetry or protected hardware data
- Proprietary CAD, technical drawings, or real spacecraft geometries
- Flight-system control or navigation code
- Classified, export-restricted, or otherwise non-releasable content

The examples are **not** calibrated to any specific spacecraft, NASA mission, heat shield, industrial facility, or flight system. They are research-education demonstrations of 1D heat conduction.

The repository is **not affiliated with, reviewed by, or endorsed by NASA, Caltech/JPL, ISRO, or any other space agency**. Individual contributors should only claim work they actually authored. Independently written sample code is not evidence of prior agency employment.

Before publishing modifications, ensure you have rights to the code/data and appropriate review for any institutional research or potentially controlled aerospace technical content.
